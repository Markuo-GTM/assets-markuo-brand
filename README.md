# assets-markuo-brand

Assets publicos de Markuo, hosteados para poder referenciarlos por URL desde lugares
que no aceptan archivos locales (firmas de email, plantillas, herramientas externas).

Repo publico a proposito: los clientes de correo de los destinatarios tienen que poder
descargar estas imagenes.
